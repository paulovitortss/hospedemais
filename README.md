# Teresina Hotel · Guia do Hóspede

Sistema web para hóspedes (foco em celular): recomendações de alimentação, mobilidade, beleza & bem-estar e vida noturna, além de serviços do hotel (recepção, limpeza, toalhas, ferro e Wi-Fi) com pedidos enviados pelo WhatsApp da recepção.

Site estático — HTML, CSS e JavaScript puros, sem build.

## Editar conteúdo

Todos os dados ficam em [`js/data.js`](js/data.js): WhatsApp e telefone da recepção, Wi-Fi, horários e a lista de estabelecimentos.

## Rodar localmente

```bash
python -m http.server 5173
```

Acesse http://localhost:5173
